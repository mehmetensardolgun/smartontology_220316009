Overview

The Academic Publication Knowledge Graph (AKPKG) ontology is an OWL 2 DL ontology for modeling scholarly publications, authors, research institutions, citation networks, research fields, and thematic keywords. It enables semantic search, citation-network analysis, and structured knowledge retrieval beyond the capabilities of traditional bibliographic databases.

The ontology also serves as the backbone for an LLM-based Natural Language to SPARQL module that translates free-text questions into structured queries using the ontology schema as grounding context. v2 Version 2.0 adds abstract-level keyword extraction, FOAF and SKOS alignments, and full Widoco-compatible annotation coverage.

SPARQL Query Examples

CQ2 — Authors of a given paper

PREFIX akp: <http://www.akpkg.org/ontology#>
SELECT ?authorName
WHERE {
  ?paper akp:title "Attention Is All You Need" .
  ?paper akp:hasAuthor ?author .
  ?author akp:name ?authorName .
}

CQ4 — Top-5 most cited papers

PREFIX akp: <http://www.akpkg.org/ontology#>
SELECT ?title ?citationCount
WHERE {
  ?paper akp:title ?title .
  ?paper akp:citationCount ?citationCount .
}
ORDER BY DESC(?citationCount)
LIMIT 5

CQ6 — Citation network (papers citing a target)

PREFIX akp: <http://www.akpkg.org/ontology#>
SELECT ?citingTitle ?year
WHERE {
  ?target akp:title "Attention Is All You Need" .
  ?citing akp:cites ?target .
  ?citing akp:title ?citingTitle .
  ?citing akp:year  ?year .
}
ORDER BY ?year

CQ11 — Abstract keyword search v2

PREFIX akp: <http://www.akpkg.org/ontology#>
SELECT ?title ?year
WHERE {
  ?paper akp:title    ?title .
  ?paper akp:year     ?year .
  ?paper akp:abstract ?abstract .
  FILTER(CONTAINS(LCASE(?abstract), LCASE("attention")))
}
ORDER BY DESC(?year)

CQ12 — Average citations per research field v2

PREFIX akp:  <http://www.akpkg.org/ontology#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?fieldLabel (AVG(?cit) AS ?avgCit) (COUNT(?p) AS ?numPapers)
WHERE {
  ?p akp:belongsToField ?field .
  ?p akp:citationCount  ?cit .
  ?field rdfs:label ?fieldLabel .
}
GROUP BY ?fieldLabel
ORDER BY DESC(?avgCit)
